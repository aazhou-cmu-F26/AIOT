Key Findings

1. The Agentic Paradox

On libcoap, triage (narrow excerpt) scored 11/11 while C1 agentic (full codebase) scored 0/11. This pattern replicates on libmodbus: triage scored 9/11, C2 crash-given scored 9/9, but C1 agentic scored 0/9. Models given code navigation tools consistently explored other potential issues instead of finding the target CVE.

Across both targets, the C1 condition achieved 0/20 accuracy on the target CVEs (only mongoose C1 at 5/9 breaks the pattern). More code exploration did not help—it distracted. Models that freely analyze a narrow excerpt refuse to converge on the same bug when given the full codebase.

Unlike libcoap's C1 runs (where Bug A was confirmed real), the libmodbus C1 hypotheses were investigated against the codebase and upstream issue tracker. GPT-5's hypothesis about memcpy(rsp, req, req_length) overflow resembles a reported crash scenario (#700), but that was traced to a caller-side bug (bad return from modbus_receive), not a library bounds failure. Other hypotheses (MAX_MESSAGE_LENGTH, modbus_set_bits_from_bytes) were not confirmed. Notably, the fn-0x17 handler had two additional CVEs post-commit (CVE-2024-36843, CVE-2024-36844 via #748/#749), but those were introduced by a later commit, not present in the vendored code.

2. Content Filtering Correlates with Condition
Filtered 63% Responded 37%

Input-drafting (asking models to construct triggering input) had 63% content filtering—the highest across all conditions. Triage-hypothesis had 0%. The same models that freely analyze vulnerability root causes refuse to construct proof-of-concept inputs. Adding libmodbus input-drafting (Modbus TCP frames) showed the same pattern: 6/9 models filtered or refused.

3. Local 7B Model Found CVE-2022-0367

qwen2.5-coder:7b (7 billion parameters, running locally on Ollama) correctly identified the copy-paste bounds-check bug in libmodbus from a narrow triage excerpt—a bug that some cloud models missed in full source review. It also found the libcoap memcpy overflow, scoring 2/4 overall.

4. Bug Difficulty Varies Sharply

libcoap triage: 100% accuracy (obvious memcpy without bounds check). libmodbus C2: 100% (crash report + excerpt). mongoose C2: 89%. libmodbus C0: 19% (subtle copy-paste error in a 1000-line function). The same model roster shows vastly different detection rates depending on the bug's syntactic visibility and how much context is provided.

5. C1 Models Independently Discovered a Real, Unreported Vulnerability

Three C1 models (GPT-5.6-sol, GPT-6.1-sol, Sonnet 5.5) independently identified a use-after-free in coap_proxy_forward_request_lkd() where the original data pointer is passed instead of body_data->s. This bug was confirmed real and fixed in upstream PR #2206 (merged Oct 30, 2026). No CVE assigned.

Two other reported bugs (proxy URI dangling pointer, PDU parse over-read) were not confirmed in the current codebase. Caveat: Training data contamination cannot be fully excluded—the libcoap source is public and UAF patterns are well-documented. However, the models found an unreported bug while failing to find the well-documented target CVE, which argues against simple memorization.
